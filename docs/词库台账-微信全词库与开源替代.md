## 二、替代策略分类学（为什么这么做）

| 策略 | 适用件 | 判据 |
|---|---|---|
| **全量开源重建** | 主词典/简拼/五笔/笔画/简繁/英文/emoji/敏感词/lmcn/bgrm | 数据即行为的词典类——开源语料（THUOCL/MIT/CC/rime 生态）充分等价，可分发 |
| **自衍生开源** | tcd 错别字对 | 腾讯对表小但语义=「高频正写锚」——从自家开源域词库统计同音对×频次比衍生，零腾讯数据 |
| **导出本地用+降级有底** | editpinyin（epyn） | S 级全解但开源无等价源（42,975 键人工校对 typo 表）；开源线缺席时引擎内建邻键/模糊音规则兜底（评测实测零影响） |
| **豁免+包线承接** | ckvd 913 万/slwd 315 万 | 用户明示豁免（「长尾词库就不用了」）；长尾承接改走 HBWC 域包/ext 包（可分发、按需挂载、无音节上限——8/8 全指标横扫见词库目录） |
| **算法内建** | prism_v2/ln2py/wpen/微件 | 结构小、行为=算法——直接复刻进引擎代码，比数据件更稳 |
| **角色等价** | sw/pskvd 联想/wtid | 按管线角色（通道/特征）用开源件重组，不逐字节对应 |
| **范围外** | hwd 手写/云词族/sequel 线/wsd/editwordt9 | 消费链未到或产品范围外；资产与逆向记录在档随时可取 |

**总纲**：词典类资产的替代深度 = 开源源充分度 × 消费链在场性。能逐位对照的
全量重建（lmcn 逐位同/主词典 golden 611）；开源无源但引擎有兜底的导出本地用；
用户豁免的走包线；算法性的内建。每件都有审计档的消费点交叉验证（在场/退场
四组 A/B 逐位对比）。
