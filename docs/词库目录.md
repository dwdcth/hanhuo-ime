## 附：微信主库 ↔ 开源对账审计（2026-11-11）

**三层结论**（审计工具: dump_wxq_words 真机测试 + set 对账）:

1. **分类层** ✓: 微信词库中心分类在开源全找到对应（25 分类, 缺源清零）。
2. **词面层**: wxq 主库 782,356 词 × 全开源并集 2,605,611 词
   （frost composite 62.2万 + 万象 jichu 149.4万 + 25 域包 92万）:
   - 域包单独只覆盖 wxq **16.7%**——域包是增量域非主库替代;
   - 加开源基座后覆盖 **54.1%**;
   - 基座是覆盖大头（jichu 149万词的「基础词库」性质使然）。
3. **残余 45.9%（35.9 万词）定性** = 非词典刚需:
   - 2-3 字聊天语料噪声（刀线/上器/不没啥/开会会 类无意义共现）;
   - 4+ 字超长尾本地专名（同心学校/火炬大街/宁夏卫视——ckvd
     642 万长尾短语库的领地, 本就不属主词典）;
   - 2 万生僻单字。

**判读**: 微信主库的开源对应 = 分类层全对齐 + 常用词层由开源基座
（open_build 线的 rime-ice / 万象 jichu）承接 + 域增量由 25 分类包
承接; 真正不可替代的是聊天语料噪声与本地化长尾（前者不需要替代,
后者由 ckvd 资产线持有）。微信细胞词库二进制（cell_dict.*.zh）为
加密 Ime trie, 未解码——分类名清单以产品公开信息+THUOCL 映射为准。
