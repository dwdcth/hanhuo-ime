# 设计：声调筛选（tone filter，万象对照缺口）

> 2026-11-10 新机 Claude 设计稿（📐 → ✅ 当日实施）。领地: query 入口语法层 +
> boost 过滤层 + tools/tone_table.py + 本文档。
> 数据归腾讯，仅本地个人研究使用，禁止外传。

## 1. 问题与价值实测

万象支持「拼音后缀声调缩围同音」（打 tian1qing1se4 直取 天青色）。
我们全链无调（wxq 无调拼音）——用户天然携带的声调信号被丢弃。

**完美声调过滤模拟**（word:common 400 样本, pypinyin 调号, 离线）:

| 输入形态 | top1 | Δ vs 基线 71.2 |
|---|---:|---:|
| 全调（轻声宽容） | **90.8** | **+19.6** |
| 非轻声词全调 | 90.7 | +19.5 |
| 仅首音节调 | 83.5 | +12.3 |
| 严格全匹配 | 93.5 | +22.3 |

零回退（基线 top1 命中无一被过滤误杀）。top3 93.3 的存量含义 =
词已在 rank2-3, 声调是用户手里现成的裁判——**单旋钮最大潜在增量**。

## 2. 机制（v1: 候选级验证过滤）

- **语法层**（query 入口）: 输入白名单扩 `1-5` 数字（其余仍整链空）。
  数字剥离 → 净输入 + 调位图（数字在净输入中的位置 = 其前字母串
  末; 语义=该位若为候选读音的音节边界, 则该音节被调约束）。
- **数据层**: `tools/tone_table.py` 由 pypinyin（MIT）生成
  字→{音节:调} 表（data/tone_solved.tsv, ~2 万字; 多音字按音节
  消歧——同字同音节多调取首调）。引擎 open 时惰性装载（epyn_tsv
  同律）; 表缺 → 旋钮静默失效（零伤害）。
- **过滤层**（boost 旋钮 `tone_filter`, 默认关; CLI `--tone-filter`）:
  对全消耗候选（reading 去撇号 == 净输入）验证——调位是音节边界
  且字×音节调号一致; 轻声 5 与候选非 1-4 调互认（宽容律）。
  **有候选通过 → 未过者移除; 零通过 → 不过滤**（优雅回退）。
  非全消耗/异长候选不动（渐进输入零影响）。
- **忠实链**: 数字本就整链空 → 语法扩展只在含数字输入上可见;
  无数字输入逐位恒等。golden 611 全小写无数字 ✓ 零扰动。

## 3. 输入语法示例

- `tian1qing1se4` → 净 tianqingse, {位4:1, 位9:1, 位11:4}
  → 天青色（tian1 qing1 se4）过; 天青涩（se4）同过——调同音
  调才分; 天清色（qing1）同过。调位不合法（如 xi1an 的 1 落
  xian 中间）→ 该候选不过。
- `shi2` → 时/识/实…（shi2 系）; 是/市 沉。
- 渐进（前缀）输入含调: 净输入变短, 全消耗判定按净输入——
  前缀候选 reading == 净输入 才过滤, 渐进面板天然不触。

## 4. 验收

- word:common 子集模拟复现 +19.6pp（引擎内实测对齐离线模拟）
- 探针: tian1qing1se4→天青色 top3; shi2→时 top3; 错调零通过→
  面板回退（不过滤）
- golden 611 / v2 零伤害（无数字输入逐位恒等）/ lib 测试
- 回退语义测试: 表缺失恒等; 零通过恒等

## 5. 风险与不做

- 多音字首调近似: 回退保护兜底（零通过不过滤）; 实测 0 回退
- 句面候选的调验证（reading==净输入的 Sentence 面）v1 同律,
  异长句面（B8 变体）不动——变体调域过滤留 v2
- 声调输出层（候选显示调号）/双拼×调交互: 不做（万象对齐最小面）

## 6. 实施与实测（2026-11-10, ✅）

- 语法层: 白名单扩 1-5; 剥离记位（净输入位→调号）。旋钮关时数字
  剥离恒等（「调号剥离恒等」测试锁）。
- 数据层: tools/tone_table.py（pypinyin heteronym 全读 × TONE3）→
  data/tone_solved.tsv（41,809 字, 多音节消歧 6,951; 428KB, MIT
  开放数据可入库）; load_tone_tab 惰性装载（data/ → crate 相对 →
  环境变量; 空表旋钮静默失效）。
- 过滤层: boost::tone_filter——调位=音节末 & 字×音节调一致
  （任一侧 5 即过的轻声宽容; 字/音节缺表 fail-open）; ≥1 过才滤
  （零过回退）。**早退面板挂点**: 单音节输入走 syl_deep 钉表面板
  早退, 不经 boost 尾段——三处早退（g1_col_solo/syl_deep/pair_panel)
  同过滤（shi2 是最高频用例）。
- 引擎内实测: word:common 377 样本 top1 71.1→**89.7（+18.6pp）**
  （离线模拟 90.8; 1.1pp 差 = 多音字引擎读数 vs pypinyin 默认）。
  探针: shi2→时 唯一 / shi4→是·事·市·室; tian1qing1se4 全消耗
  语义正常（色/涩 同调不拆——调只分调, 不拆同调字）。
- 门: golden 611（无数字输入逐位恒等）/ v2 零伤害（common 93.3
  等基线逐位同）/ lib 171 + 真机 tone_filter_single_syllable_split。
- CLI: --tone-filter（双登记）; TONE_DBG 调试钩子。

## 7. v2 修复与句级增量（2026-11-10 二轮）

初版句级调号输入实测**负增量**（top1 0%）——三坑连环:

1. **query_typo_retry 带调编排**: 重试入口收原始数字串, dp 死窗/变体
   域在数字串上瞎算（恒死→误入变体域, 全链劣化）。修复 = 共享
   `strip_tones` 双入口同律 + 重试编排净串化 + 终面板过滤（wrapper）。
2. **Sentence 面缺 reading**: 过滤器原依赖 reading==净输入, 句面
   reading 空 → 恒不可滤。修复 = **调表贪心游走**——逐字在表中找
   净输入前缀音节（最长优先）, 整消耗即全消耗（字×音节自证）,
   与 reading 无关; 复合词面（连接符复合形）按显示形验证。
3. **轻声表缺**: pypinyin TONE3 把轻声渲染为**无数字尾形**（的→de）,
   生成器按尾数字解析把全部轻声读音丢弃（的 只剩 di1）。修复 =
   无尾数字=调5 律。的=de5·di1 / 吧=ba5。

**宽容律改非对称**: 候选 ct=5（吧 类轻声读）不再豁免——打 ba2 即
非 吧(ba5) 读; 仅用户打 5 宽容任意候选调。

终值:
- 词级 word:common 400 样本 top1 71.2→**90.5（+19.3pp）**（初版
  89.7 → 轻声表修复+非对称再 +0.8）
- 句级（B7+B8 臂 + 调号）: top1 32.7→**35.3（+2.6pp）**, frag@3
  96.1 / frag@10 **98.0**——排序残局（模型判别力闭卷 32.7）被
  用户调号信号部分重开; 增量受两限: pypinyin 生成调 py 的读音
  漂移 + 面先要在池中（可达性残局）
- 句级默认臂无增益（25.5/90.2——无变体池可滤, 且读音漂移净负）:
  调号句级收益绑定 B8 变体束臂
