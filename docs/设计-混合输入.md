# 设计：全拼+简拼混合输入（backlog input_domains GAP）

> 2026-11-09 新机 Claude 设计稿（📐 阶段——本文为实施前设计, 未动引擎）。
> 数据归腾讯，仅本地个人研究使用，禁止外传。

## 1. 问题与实测现状

真实打字模式：长句渐进输入中**中途切简拼**（前几个音节全拼、余下声母）。

| 探针 | 期望 | 现状 top1（实测 2026-11-09）| 病理 |
|---|---|---|---|
| tianqsdy | 天青色的 | 天气啥都有 | greedy L1 吃掉 tian 后 q-s-d-y 全走逐字 fuzz——**全拼段已付出的意图被丢弃** |
| tqsdyu | 天青色等雨 | 铁器时代色域（+16 钉分）| 全声母串进 G2 fuzzcomp 任意组合 |
| jintiantq | 今天天气 | 今天阿奇 | 今天 识别后 t-q 逐字 |

根因：切分域二分法（合法全拼切分 ↔ 纯声母串）之间没有**混合域**——
fuzzcomp 只吃纯简拼（`_q_fuzzcomp` 首字母列校验），L1 死段即整链降级。

## 2. 设计：L1.5 混合切分 + 段类型化组装

### 2.1 混合切分 DP（greedy → DP）

`mixed_reach(inp)`: 位置 i 可走两种转移——
- **全拼段**：inp[i..j] 是合法音节（j-i ≤ 7，贪心同律）
- **声母段**：单键 b/p/.../zh/ch/sh（双键声母整体——zh/ch/sh 不可拆，
  与 B2.6 键级枚举同律）

产出：位图 reach + 回溯得 k-best 混合切分（全拼段多的优先——
用户全拼是更强意图信号）。

### 2.2 组装：复用 c.3 词块机制（jianpin_block_parts 泛化）

c.3 的 `jianpin_block_parts` 已实现「每位置单字∪多音节词块」部件枚举
——泛化点只有一处：**全拼段位**的转移集从「单字 top-K + 词块」收窄为
「该音节 reading 列」（全拼已定音节, 无枚举空间; 词块仍可叠加——
全拼段被多音节词块吞并= 用户少打的声母位, 加权偏好）。

结构（重用 JpParts）：
- `mixed_block_parts(inp)`: 位转移 = 全拼段（reading 列 top-M）∪
  声母段（单字 top-K ∪ 词块 DFS）——**与 c.3 部件层同构**,
  声母段行为 = 现有实现原样。

### 2.3 排序：三态域路由

| 场景 | 排序 | 机制现成度 |
|---|---|---|
| 无 ctx | Σlp 频序（B2.6b 同律——无语境时逐字/块频序已对）| 新: 面板注入走 B0/B2.7 钉序 |
| 有 ctx | **直接进 c.3**（NNLM 引导束——域门从「非合法全拼切分」扩为「含声母段的混合切分」）| 一行域门改判 |

### 2.4 域门与零伤害

- 触发门：`mixed_reach` 可达 且 纯全拼 greedy **不可达**（纯全拼走原链
  ——混合层纯增量）; 纯声母串 = 混合切分的特例（全声母段）, c.3 域
  门语义自然涵盖。
- golden 忠实链：boost 旋钮 `mixed_input: bool`（默认关）; 过 v2 common
  零伤害门后议升默认。
- zh/ch/sh 声母段与 B2.7 简拼表键的 z/c/s 投影冲突：混合域直接按
  双键声母整体处理（zh 就是 zh）, 与简拼表域互斥（键域不同不叠加）。

## 3. 工作量与验收

- 混合切分 DP + 部件泛化：~1 天（c.3 部件层复用 80%）
- 无 ctx 频序面板注入：~0.5 天
- c.3 域门扩判 + 探针：~0.5 天
- 验收：tianqsdy→天青色的 top3、jintiantq→今天天气 top3、
  tqsdyu→天青色* top10（无 ctx）; 带ctx 进 c.3 质变链。
  golden 611 零扰动 + v2 common 门。

## 4. 风险

- 混合切分歧义（tianqsdy 的 t-ian 也合法）: k-best 全保留进部件层,
  NNLM/频序裁决——不在 L1.5 提前剪。
- 全拼段+词块吞并的权重偏好（2.2）需实测标定, 首版可不加权
  （词块 lp 已含频次信息）。

## 5. 实施与实测（2026-11-10, 🔧→✅）

### 5.1 落地形态

- 旋钮 `--boost-mixed`（BoostCfg.mixed_input, 默认关——golden/v2 零行为）。
- `boost::mixed_segs`: 贪心混合切分（最长全拼优先, 死位回退声母段,
  zh/ch/sh 双键整体）→ 虚拟串 + 位置→精确音节约束; 门 = 长度 [3,12] ∧
  全拼段≥1 ∧ 声母段≥1（纯声母归 c.3, 纯全拼归原生 DP）。
- `jianpin_block_parts_constrained`: 部件层泛化——全拼段位 singles 只取
  该音节 reading 列 top-24, 块 DFS 每步过约束（块吞并全拼段合法——
  天青色 吞并 tian 段即此路径）; 混合串每音节长度席位 8→12
  （tqsdyu 实证: 天青色 -6.36 在 8 席下被 9 个更高频 t 块挤出,
  ctx-NNLM 失去裁决机会; 纯声母域 8 席零变化）。
- 域路由: typo_retry 不可达分支先判 mixed_segs 可达 → 原链跑原始输入
  （dp=false 免死输入慢通道）; 无 ctx 频序钉分注入 cap4;
  有 ctx 且 c.3 在场（旋钮+NNLM）时让位 ctx_jp_compose（部件源接
  mixed_segs 适配器, beam 束面含约束块）。

### 5.2 实测病理与修复（两坑）

1. **typo 变体污染**: 不可达输入的原链查询从不运行（面板全来自
   q→a 类变体查询）, 变体混合面「今天昂起」挤掉原始面——修复 =
   不可达分支混合域判先行（§5.1 域路由）。
2. **部件层席位截断**: 见上, 混合串席位放宽。

### 5.3 探针结果

| 探针 | 无 ctx | 有 ctx（adv NNLM） |
|---|---|---|
| jintiantq | 今天天气 top2 ✓ | 同稳（top2） |
| tianqsdy | 天青色的呀 在部件终集（lp -10.7）, 面板外 | ctx=天青色等烟雨而我在等你 → 天青色* 占 top5 四席（top1 天青石第一/top2 天青色第一） |
| tqsdyu | 同上（-10.8 级） | ctx=青花瓷前句 → 天青色对于 top3/top4 |

无 ctx 两探针的 天青色* 目标（top3/top10）结构性不可达: 竞品面靠
3-4 音节搭配块（是的呀 -4.2 / 前世的缘 类）, singles 路 lp 劣势
~1.5-2.5; 全拼段块吞并加权（§2.2）评估过——拉开 天气 面需 λ>1.3/键
（单字 lp 量级, 畸变）, 且对 tqsdyu 反向伤（yu 段块如 地狱 同获加权）。
定案: 无 ctx 频序保持 B2.6b 同律, 该类面交 ctx-NNLM 臂。

### 5.5 残余收尾（2026-11-10 二轮）

- **槽数门修复**: 门从原始字节长（≤12B）改为虚拟槽数（3..=12）——
  全拼段多字母折叠 1 槽, chongmanjiqdbsh（14B/7 槽）曾被字节门
  误杀。153 探针集 top10 10.5→15.0。
- **混合域评测集**（eval/eval_mixed.jsonl + tools/mixed_eval.py,
  153 条: 句前缀 k=2·3 全拼 + j=3·4·5 声母渐进形）: 基线 0/0/0
  （混合键无旋钮完全死域——设计稿病理定量坐实）→ --boost-mixed
  top1 7.8 / top3 11.1 / top10 15.0。
- **无 ctx 残局定性**: 失败主体 = 搭配块频序墙（充满激情的不是 vs
  充满激情的跋涉——不是(bu'shi) 块频压 跋+涉 单字; 河钢就当我 vs
  和刚交的网友 同型）——与整句排序残局同物理, 出路同为域词/ctx。
  注入 cap4 非瓶颈（注入面已达 top4 区）。
- **zh 双键域互斥边界探针** ✓: zhonggh→中国好 top1 精确（zh 全拼
  段+g·h 声母）; zhzh 纯声母正确归 c.3（这哈/这咋 原生简拼面）;
  zhongg 的 typo 变体走混合路径行为一致。
