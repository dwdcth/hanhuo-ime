# 词库下载与重建指南

> 2026-11-11。「微信式分库」25 分类的获取、挂载、重建一站式手册。
> 词包本体（data/domain/*.hbwc）不入 git（体积+混源许可），本文是
> 任何人从零复现全部词库的完整路径。

## 一、总览

```bash
hanhuo dicts          # 列出 25 分类（名/包/词数/许可/源）
# 挂载（可多包同挂，跨包同拼自动去重）:
hanhuo query nihaoshihaimian --dict data/domain/idiom.hbwc --boost-inj-top
```

| 想要 | 走 |
|---|---|
| 直接用已建包 | 本机 `data/domain/*.hbwc`（§三 挂载旋钮） |
| 从开源源重建某分类 | §二 对应小节（clone 源仓 → 跑导入器） |
| 全量重建 | §二 末尾「一键序列」 |

依赖（一次性）: `pip install pypinyin opencc jieba`

## 三、挂载与旋钮

```bash
--dict <file>            # 挂载一个包（可重复多包）
--boost-inj-top          # B2w-τ: 打全领域词拼音即钉序置顶（词级 top1 兑现）
--boost-bwcn-sent        # 句级域词格（B8 变体束, 长句域词入组）
# ctx 搭配（上文选词后续打）: --ctx 天下 → 共主 登顶（τ2 词典搭配直提,
#                         需上文旋钮 --boost-nn --boost-tail）
```

示例:

```bash
# 词级: 打成语拼音直取
hanhuo query hushihaoxiongdi --dict data/domain/idiom.hbwc --boost-inj-top
# 句级: 长句挂歌词包组句
EVAL_DICTS=data/domain/lyric.hbwc python3 tools/sentence_eval.py ...
```

## 五、排障

- **导入器报源仓不存在**: 检查 §二 的 clone 路径（脚本默认 `~/tmp/<名>`）。
- **lyric 语料解压失败**: zip 内有超长文件名（串烧合集），用
  `python3 - <<'EOF' ... zipfile 容错解压`（见 lyric_import 文档串）。
- **`hanhuo dicts` 无目录**: catalog.json 缺失时先跑任一导入器或
  从 git 取（仓内随附 data/domain/catalog.json）。
- **重建后数字对不上基线**: 见 docs/评测-领域基线.md 各包基准值。
